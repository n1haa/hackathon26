# CashFlow AI

Демонстрационный интерфейс финансового SaaS для малого бизнеса. Сейчас приложение содержит только UI и синтетические примеры: загрузка выписки показывает предпросмотр файла, но не выполняет финансовый анализ.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## Разделы

- Финансовый обзор с KPI, графиком денежных потоков, рисками и последними операциями.
- Загрузка CSV/XLSX с предпросмотром выбранного файла.
- Операции с поиском и фильтрами.
- Регулярные платежи.
- Финансовый прогноз с переключением горизонта 7/30/90 дней.
- Финансовые риски с демонстрационными сценариями.

Все демонстрационные данные находятся в `cashflow/demo_data.py`. Слой `cashflow/data_access.py` отделяет данные от интерфейса и подготовлен к будущей замене источников.
